# Asking Your Crush Out

Interactive confession microsite with theme options, short-link generation, and playful response flows.

## Features

- Landing + create flow with animated variants
- Share link shortener endpoints (`/api/shorten`, `/api/resolve`)
- Multiple themed after pages

## Run Locally

```powershell
cd "asking your crush out"
npx --yes serve . -l 8080
```

Open: `http://127.0.0.1:8080/index.html`

## Test

```powershell
cd "asking your crush out"
npm test
```
